# YASB - Tokyo Night

This folder contains my personal **YASB** configuration for my Tokyo Night setup.

Most of the configuration comes from **Darren Lingters**, whose Windows customization work has been an important reference and source of inspiration for my own setup. The configuration may sometimes be edited or adapted by me to fit my personal setup.

## Installation

1. Install **YASB**.
2. Open the YASB configuration folder.
3. Back up your existing configuration files.
4. Copy the files from this folder into your YASB configuration folder.
5. Replace the existing files if prompted.
6. Restart YASB to apply the changes.

> **Important:** Make a backup of your original configuration before replacing it.

## Configuration

This setup includes both the YASB configuration and its custom stylesheet.

The configuration includes:

* A top bar across all screens
* Komorebi workspace integration
* Active Komorebi layout display
* Active window information
* Clock and calendar
* Media controls
* Audio visualizer
* System tray
* CPU and memory monitoring
* Volume controls
* Notifications
* Keyboard language indicator
* Wallpaper management
* Windows Control Center
* Rounded corners and adaptive bar styling 

The stylesheet uses a **Tokyo Night** color palette with the standard Tokyo Night background, foreground, accent, hover, border, and red highlight colors. 

The stylesheet also defines custom rounded corners, widget spacing, bar styling, menus, Komorebi workspace elements, system information panels, and other UI components. 

## Files

* `config.yaml` - Main YASB configuration
* `styles.css` - Custom Tokyo Night stylesheet
