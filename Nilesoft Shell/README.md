# Nilesoft Shell - Tokyo Night

This folder contains the Tokyo Night theme for Nilesoft Shell.

## Installation

1. Open the Nilesoft Shell configuration folder.
2. Copy `theme.nss` from this folder.
3. Paste it into the Nilesoft Shell configuration folder.
4. Replace the existing file if prompted.
5. Reload Nilesoft Shell to apply the changes.

> **Important:** Make a backup of your original `theme.nss` before replacing it.
