# Komorebi - Tokyo Night

This folder contains my personal **Komorebi** configuration for my Tokyo Night setup.

Most of the configuration used here comes from **Darren Lingters**, whose Windows customization work has been an important reference for my setup. The configuration may sometimes be edited or adapted by me to fit my personal setup, including changes to the Tokyo Night theme or other settings.

## Installation

1. Install **Komorebi**.
2. Open the Komorebi configuration folder.
3. Back up your existing configuration files.
4. Copy the configuration file from this folder into the Komorebi configuration folder.
5. Replace the existing configuration if prompted.
6. Restart Komorebi to apply the changes.

> **Important:** Make a backup of your original configuration before replacing it.

## Configuration

The configuration contains my personal setup for:

* Window management
* Workspace layouts
* Multi-monitor workspaces
* Window padding
* Transparency
* Window hiding behaviour
* Cross-monitor window movement
* Applications excluded from Komorebi

The configuration uses Tokyo Night colors, including `#e0af68` and `#9aa5ce`. 

### Workspaces

**Monitor 1**

* `I` → BSP
* `II` → Grid
* `III` → HorizontalStack

**Monitor 2**

* `Home` → Rows
* `2` → Rows
* `3` → Rows 

### Ignored applications

The configuration excludes several applications from Komorebi management:

* `ACShadows.exe`
* `Overwatch.exe`
* `Photos.exe`
* `PotPlayerMini64.exe`
* `Elgato.WaveLink.exe`
