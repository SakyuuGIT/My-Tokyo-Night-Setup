# Windows Terminal - Tokyo Night

This folder contains my Tokyo Night configuration for Windows Terminal.

## Installation

1. Open **Windows Terminal**.
2. Open **Settings**.
3. Select **Open JSON file** at the bottom of the Settings menu.
4. Open the `settings.json` file provided in this folder.
5. Copy the contents of the provided `settings.json`.
6. Back up your existing `settings.json`.
7. Replace the contents of your existing `settings.json` with the provided configuration.
8. Save the file.
9. Restart Windows Terminal if necessary.

> **Important:** Replacing `settings.json` will overwrite your existing Windows Terminal configuration. Make a backup before replacing it.

The provided configuration contains the Tokyo Night theme and related Windows Terminal settings.
