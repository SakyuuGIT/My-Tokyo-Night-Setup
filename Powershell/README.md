# PowerShell - Tokyo Night

This folder contains the Tokyo Night configuration for Windows Terminal / PowerShell.

## Installation

1. Open Windows Terminal.
2. Open **Settings**.
3. Select **Open JSON file** at the bottom of the Settings menu.
4. Open the `settings.json` file provided in this folder.
5. Copy the contents of the provided `settings.json`.
6. Replace the contents of your existing `settings.json` with it.
7. Save the file.
8. Restart Windows Terminal if necessary.

> **Important:** Make a backup of your existing `settings.json` before replacing it.

The provided configuration contains the Tokyo Night theme and related Windows Terminal settings.
