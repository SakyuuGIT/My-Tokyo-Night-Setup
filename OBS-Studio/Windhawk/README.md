# Windhawk - Tokyo Night

This folder contains the Tokyo Night configurations for my Windhawk mods.

## Installation

1. Open the Windhawk mod you want to customize.
2. Open the **Advanced** settings.
3. Go to the **Text** mode.
4. Open the corresponding `.txt` file from this folder.
5. Copy all of its contents.
6. Paste the contents into the **Text** mode of the Windhawk mod.
7. Apply the changes.

Each `.txt` file corresponds to a specific Windhawk mod.
