# VS Code - Tokyo Night

This folder contains the instructions to install the Tokyo Night theme for Visual Studio Code.

## Installation

1. Open **Visual Studio Code**.
2. Open the **Extensions** panel.
3. Search for **Tokyo Night**.
4. Install **Tokyo Night** by **enkia**.
5. Open the Command Palette with `Ctrl + Shift + P`.
6. Search for **Preferences: Color Theme**.
7. Select **Tokyo Night**.
